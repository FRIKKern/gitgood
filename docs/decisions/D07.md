# D07 Consistent backup

Status: implementation experiment in progress; coordinated restoration is not yet accepted.

## Question

Select a coordinated recovery point across repositories, databases, adopted Barkpark stores, assets, and keys.

## Experiment

Prototype bounded write-pause backup; restore elsewhere and verify metadata, permissions, clone, and push.

The selected initial experiment uses a stopped single-host runtime, installation exclusion and process-owner checks before reading PostgreSQL, native Git/import/recovery files, SSH identity and encrypted-credential configuration. An authenticated encrypted bundle and a separate immutable artifact set must restore onto a replacement Ubuntu 24.04 x86-64 host. See [implementation and remaining proof](../implementation/offline-backup.md). A database dump alone and a same-host restart do not establish the exit gate.

## Exit gate

Before backup/restore is called supported.

Alternatives; pinned versions; fixture and commands; observations; result; remaining uncertainty; recommendation; rationale; owner and decision date. No experiment result is claimed by this document.

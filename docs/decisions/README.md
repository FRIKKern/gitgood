[Isolated retirement verification](0011-isolated-retirement-verification.md) defines
the temporary restored copy and continuous original custody boundary. Its design
is accepted; installed pre-removal function and stopped-marker observation have
passed scoped checks. The separate post-removal profile completed the fixed
five-stage installed disposable case; native lifecycle CLI and managed Cloud remain open.

[Post-removal retained usability](0012-post-removal-retained-usability.md) defines
separate exact source absence and repeated fixed target function. Its execution
design is accepted; eleven actual installed lifecycle checks, seven refusal checks
and two unchanged terminal CLI observations passed. Current required CI/integration
remains separate from that installed proof.

[Fixed native retirement execution](0013-fixed-native-retirement-executor.md)
defines the single owner command, independently bound private inputs and fixed
stage reconciliation. Actual continuation, pre-import owner-loss recovery and
ordinary all-five-stage CLI execution each passed five checks plus two terminal
calls. Exact committed applicability and126/122/117-file archive readback passed;
its required CI remains a separate integration gate.

[Fixed native upgrade commands](0014-fixed-native-upgrade-commands.md) exposes the
existing enrolled-installation engine through execution, compatible previous-code
recovery and forward-repair choices. Actual seven-stage execution, wrong-artifact
refusal, compatible recovery and migration-owner loss/forward repair passed with
later-session API/HTTPS/SSH function. A 322-file private archive passed readback;
exact committed applicability and required integration CI remain separate gates.

[Durable first-install owner bootstrap](0015-installation-owner-bootstrap.md)
defines a separate fixed first-owner request, atomic creation receipt and
historical replay without resetting credentials or changed memberships. Nine
real-Postgres component checks passed; complete installation and packaged
production execution remain separate work.

# D04 Native Git transport
Status: initial contract accepted, 8 October 2026. Owner: Codex under delegated project authority.

The chosen design is [native stateless pack commands with Elixir authority](0003-native-http-transport.md).
Git HTTP CGI was considered, but the available Windows MinGit distribution omits http-backend.
Direct pack commands passed real trusted HTTPS client tests on Windows; PR #8 repeats them on Ubuntu.

Evidence: scoped read/write identities, denied protected writes, credential revocation, invalid TLS trust,
interrupted upload/retry, request/output/time/memory/concurrency limits, descendant cleanup and strict fsck.
Reproduction is in [implementation evidence](../implementation/README.md).
Git 2.53.0.windows.3, Python 3.12.14, Elixir 1.20.4, OTP 29.1.1 and Postgres 18.4 were used locally.
Broader clients, tags, LFS, compression and larger packs need subsequent experiments.
This initial acceptance does not establish full hosting or release readiness.

# Gitgood documentation

[Repository home](../README.md) · [Progress snapshot](STATUS.md) · [Run locally](DEVELOPMENT.md) · [Find the code](CODEBASE.md)

Gitgood is a private-team forge built with Elixir, Postgres and standard Git, with a React/TanStack interface. Start with the question you want to answer; you do not need to read the implementation archive to understand the project.

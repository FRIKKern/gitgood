# J03 Use and revoke SSH credentials

## Preconditions

Use synthetic fixtures and isolated stores. Record code/spec revisions, runtime versions, actual actors, and the relevant configuration. Milestone membership is defined in catalog.json.

## Acceptance criteria

- **J03-A:** A user adds a supported SSH public key and clones/pushes within their repository role.
- **J03-B:** A key cannot acquire another user's identity or a broader role. Define duplicate key policy. A revoked key is refused on new operations; document in-flight behavior.
- **J03-C:** Failure between key registration and availability remains visible and retryable without duplicate attribution.

## Evidence

Real SSH Git transport, revocation, read-only role, and audit attribution checks.

A result must identify which of the criteria above it establishes. Store manifest references; keep private artifacts access-controlled. Unimplemented or unmeasured behavior stays unverified.

Applicable invariants: I01, I02, I08. See [quality rules](../../QUALITY.md).

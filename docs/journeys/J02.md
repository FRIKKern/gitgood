# J02 Clone and push over HTTPS

## Preconditions

Use synthetic fixtures and isolated stores. Record code/spec revisions, runtime versions, actual actors, and the relevant configuration. Milestone membership is defined in catalog.json.

## Acceptance criteria

- **J02-A:** An authorized contributor clones an empty repository, commits, pushes, and fetches the expected ref with a real Git client.
- **J02-B:** A read-only actor cannot push. A denied or malformed ref update leaves protected refs unchanged. Credentials are absent from logs and process arguments where avoidable.
- **J02-C:** Interrupt a push and verify ref/object integrity; enforce timeout, size, concurrency, and child-process cleanup boundaries.

## Evidence

Real Git client integration with temporary stores, denied credentials, interrupted process, and ref checks.

A result must identify which of the criteria above it establishes. Store manifest references; keep private artifacts access-controlled. Unimplemented or unmeasured behavior stays unverified.

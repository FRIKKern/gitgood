# J07 Receive external check results

## Preconditions

Use synthetic fixtures and isolated stores. Record code/spec revisions, runtime versions, actual actors, and the relevant configuration. Milestone membership is defined in catalog.json.

## Acceptance criteria

- **J07-A:** An identified provider reports results tied to the repository, revision, check identity, and execution attempt.
- **J07-B:** Reject unauthorized reports; prevent a stale revision result from satisfying current policy. Define ordering of pending/running/final reports.
- **J07-C:** Duplicate or out-of-order deliveries remain attributable and converge according to the provider contract. Failures are retryable and bounded.

## Evidence

Authenticated API integration, replay, stale/out-of-order payloads, policy evaluation tests.

A result must identify which of the criteria above it establishes. Store manifest references; keep private artifacts access-controlled. Unimplemented or unmeasured behavior stays unverified.

## Rules

Applicable invariants: I02, I03, I04. See [quality rules](../../QUALITY.md).

## Completion

All criteria need current evidence against the intended build and requirement revision. Record limitations and open failures in the ledger. Product/reviewer acceptance follows QUALITY.md.

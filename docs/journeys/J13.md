# J13 Search and follow activity

## Preconditions

Use synthetic fixtures and isolated stores. Record code/spec revisions, runtime versions, actual actors, and the relevant configuration. Milestone membership is defined in catalog.json.

## Acceptance criteria

- **J13-A:** Find permitted repository/work records and receive relevant activity with stable links and timestamps.
- **J13-B:** No inaccessible data leaks through snippets, counts, subscriptions, or caches. Define how permission changes invalidate derived views.
- **J13-C:** Reconnect or detect event gaps and refetch; unavailable source is not an empty successful result.

## Evidence

Native discovery starts with permitted repositories, pull requests, releases and actual audit records. Supported external work records retain their source ownership and availability under J10. New links and cursor positions must not reveal global internal sequence counters. Current-session read callbacks serialize with credential revocation and membership changes; browser caches additionally need explicit account/change/reconnect invalidation. See the experimental [discovery decision](../decisions/0008-private-discovery.md).

Two-user cache/search/event checks, permission revocation, dropped/replayed events, browser recovery.

The native implementation uses complete recent snapshots rather than a sequence subscription. Exercise a delayed permitted response after an owner removes access, replay an older snapshot and replace it with a fresh one, and distinguish a failed source from zero matches. Check cross-tab logout/account replacement, inactive/offline views, selected older review UUIDs and upgrade/restart preservation. Owner membership changes are exercised through the native UI/API with expected-role and idempotency checks; retain their audit UUIDs and last-owner concurrency proof. External Barkpark work remains separately verified under J10.

A result must identify which of the criteria above it establishes. Store manifest references; keep private artifacts access-controlled. Unimplemented or unmeasured behavior stays unverified.
